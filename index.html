Embedded Vision & TinyML Memory Optimization

Designed memory-constrained embedded vision pipelines using the Cortex-M85 based Renesas EK-RA8P1. Resolved strict SRAM and Flash ceilings by engineering double-buffered zero-copy DMA capture pipelines alongside TFLM workspace allocations for high-efficiency image inference.

Target: Sub-2MB SRAM Footprint
Result: Real-time zero-copy pipeline
