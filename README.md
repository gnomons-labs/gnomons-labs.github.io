# Gnomons — Landing Page

Marketing landing page for Gnomons, hosted via GitHub Pages.

## Live site

https://www.gnomons.com

## Files

- `index.html` — the landing page
- `logo.png` — brand icon (used in the header)
- `wordmark.png` — "Gnomons" wordmark image (used in the header)
- `favicon.ico` — browser tab icon

All image files must stay in the same root directory as `index.html`, since they're referenced with relative paths.

## Local preview

Open `index.html` directly in a browser, or serve the folder locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
